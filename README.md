# 이야기 공방 — Windows용 2D RPG 제작 툴

[**Windows 최신 설치 파일 다운로드**](https://github.com/sodo6809-ship-it/story-forge/releases/latest/download/StoryForge-Setup.exe) · [버전별 변경 사항](https://github.com/sodo6809-ship-it/story-forge/releases)

설치 후 앱 상단 **업데이트 → 업데이트 다운로드 → 저장하고 업데이트**로 최신 버전을 적용합니다.

## 설치와 실행

1. `StoryForge-Setup.exe`를 실행합니다. Windows 10/11 64비트용입니다.
2. 사용자 계정에 설치되며 바탕화면에 **이야기 공방** 바로가기가 생깁니다.
3. 실행하면 ‘솔바람 마을의 작은 열쇠’ 예제가 열립니다. **F5**로 먼저 플레이해 보세요.

설치 파일에는 실행 환경이 포함되어 있어 Node.js·Python·별도 서버가 필요하지 않습니다. 설치 후 인터넷 없이 작동합니다. 제작자 코드 서명이 없는 초기 빌드이며, Windows에서 게시자를 확인할 수 없다는 안내가 나올 수 있습니다.

## 첫 게임 만들기

- **새 프로젝트**: 빈 맵에서 시작합니다. 기존 작업을 먼저 저장하세요.
- **맵 추가 / 맵 설정**: 여러 장소를 만들고 이름·크기·배경을 바꿉니다.
- **붓 / 채우기 / 지우개**: 타일을 선택해 그립니다. 바닥과 장식을 분리해 편집합니다.
- **통행 설정**: 왼쪽 클릭은 막기, 오른쪽 클릭은 허용, 지우개는 타일의 기본 통행으로 복원합니다.
- **시작 위치**: 주인공의 시작 칸을 지정합니다.
- **이벤트**: 칸을 눌러 대화, 상자, 문 등을 놓습니다. 오른쪽 목록으로 기존 이벤트를 선택할 수도 있습니다.
- **플레이**: 편집 원본과 분리된 임시 상태에서 시험합니다. 돌아오면 이벤트·아이템 설정은 그대로입니다.

## 내 그림 사용하기

‘그림과 타일 → 불러오기’에서 PNG·JPG·WebP를 넣습니다.

| 용도 | 지원 방식 |
|---|---|
| 타일 | 16·32·48px 격자로 분할하거나 그림 전체를 한 타일로 등록 |
| 캐릭터 | 한 장 또는 가로 3프레임 × 세로 4방향 시트 |
| 대화 얼굴 | 대화 명령에서 선택해 표시 |
| 맵 배경 | 맵 설정에서 선택. 타일 아래 배경으로 표시 |

캐릭터 시트의 방향 순서는 **아래 / 왼쪽 / 오른쪽 / 위**입니다. 모든 맵 타일과 캐릭터는 게임에서 기본 32px 칸을 기준으로 맞춰집니다. 자동 타일 규칙과 RPG Maker 다중 캐릭터 시트 자동 해석은 아직 없습니다. 다중 캐릭터 시트는 캐릭터 한 명의 3×4 영역으로 먼저 잘라 주세요.

그림은 프로젝트에 포함되므로 원본 이미지의 경로가 바뀌어도 유지됩니다. 이미지당 12MB, 가로·세로 4096px 이하를 지원합니다. 맵은 5~96칸, 프로젝트당 최대 30개입니다. 사용자 타일과 그림은 최대 2048개이며, 파일 크기는 64MB 이내를 권장합니다.

## 이벤트 만들기

이벤트 명령은 위에서 아래로 실행합니다.

- **대화**: 이름, 본문, 얼굴 그림을 지정합니다.
- **선택지**: 두 답변을 만들고, 각 답변의 후속 대사와 켤 스위치를 지정합니다.
- **아이템**: 이름과 수량을 지정합니다. 음수 수량은 소모합니다.
- **스위치**: 같은 이름의 상태를 켜거나 끕니다.
- **맵 이동**: 목적지 맵과 좌표를 지정합니다. 좌표는 0부터 시작합니다.

실행 조건으로 ‘스위치가 켜짐’ 또는 ‘아이템을 소지함’을 사용할 수 있습니다. 조건 미달 대사를 따로 넣을 수 있고, ‘한 번만 실행’을 켜면 상자 등의 보상을 반복해서 받지 않습니다. 아이템 이름과 스위치 이름은 일치해야 연결됩니다. 선택지에서 스위치를 켠 뒤, 다른 이벤트의 조건에서 같은 스위치를 사용해 이야기를 이어갈 수 있습니다.

- **조사 이벤트**: 그 칸을 바라보고 Enter 또는 Space.
- **접촉 이벤트**: 해당 칸에 들어가면 실행. 통행 막기를 해제해야 합니다.

## 예제 플레이

마을 중앙에서 안내인에게 말을 걸어 선택지를 시험해 보세요. 서쪽의 상자를 조사하면 오래된 열쇠를 받습니다. 열쇠를 가진 채 집 문으로 들어가면 집 내부로 이동합니다. 편지를 읽고 출구로 돌아올 수 있습니다.

## 저장과 내보내기

- **저장**: `.storyforge` 파일로 저장합니다. 그림·맵·이벤트를 함께 담습니다.
- **다른 이름**: 프로젝트의 복사본을 만듭니다.
- **자동 복구**: 수정 후 잠시 지나면 PC 앱 데이터에 복구본을 보관합니다. 다음 실행 시 이어갈지 선택합니다. 직접 저장을 대신하는 기능은 아닙니다.
- **게임 내보내기**: 에셋과 실행 코드를 모두 포함하는 HTML 한 파일을 만듭니다. 제작 툴 없이 일반 브라우저로 열어 플레이할 수 있습니다. 터치용 이동·조사 버튼도 들어 있습니다.

첫 버전의 내보낸 게임에는 **게임 진행 저장 / 소리 편집 / 플러그인 / 자동 타일**이 없습니다. 제작 프로젝트 저장과 게임 플레이 진행 저장은 다른 기능입니다. 제작 도구는 PC 설치형이며, 내보내는 게임은 현재 HTML 형식입니다.

## 개발 및 검증

이 저장소에 전체 편집 가능한 소스가 들어 있습니다. 코드는 MIT 라이선스입니다. 사용자 이미지의 권리는 각 소유자에게 있습니다. 기본 타일과 캐릭터는 이 프로젝트의 절차적 픽셀 그래픽이며 RPG Maker의 독점 에셋을 포함하지 않습니다.

개발 환경: Node.js 22 이상. `npm ci`, `npm start`로 실행하고 `npm run dist`로 Windows 설치 파일을 만듭니다. Electron 44.5.1 / electron-builder 26.15.3 버전을 고정했습니다.

GitHub의 Windows 환경에서 설치 파일 생성과 설치·제거를 자동 검증합니다. 실제 Windows GUI 플레이는 별도 확인이 필요합니다. 엔진 시나리오, 편집 UI, 그림 가져오기, 파일 왕복, 플레이 및 HTML 내보내기는 별도 테스트로 확인합니다. 실제 PC에서 설치나 실행 문제가 생기면 오류 화면을 전달해 주세요.

## 0.3.0: 횡스크롤 액션과 화면 연출

왼쪽 **게임 모드**에서 탑다운 RPG / 횡스크롤 액션을 선택합니다. 기존 맵·이벤트·그림은 보존됩니다. 모드를 바꾼다고 지형이 자동 변환되지는 않으므로, 빈 공간과 발판을 편집하세요. 처음에는 **횡스크롤 예제 열기**로 시작하는 것이 편합니다. 예제를 열기 전 기존 작업을 저장하세요.

### 캐릭터와 맵

- **캐릭터 동작**: 기본 캐릭터의 3~5등신 비율, 그림 너비·높이, 충돌 너비·높이, 체력·이동·점프·공격을 설정합니다. 내 캐릭터 그림은 지정한 크기로 표시됩니다.
- 캐릭터와 적은 **발 위치**에 정렬됩니다. 시작 위치 위에 몸이 들어갈 빈 공간을 확보하세요.
- **횡스크롤 빈 공간** 타일로 공간을 비웁니다. 발판은 돌 등 타일을 놓고 **통행 설정 → 왼쪽 클릭**으로 막습니다. 지우개의 바닥 기본값은 빈 공간입니다.
- 방향키 / A D 이동, Space 점프, Z 근접 공격, X 연타 탈출, Enter 조사, I 가방. 화면 아래 버튼도 사용할 수 있습니다.
- 이번 액션은 기본 근접 전투입니다. 경사면, 사다리, 아래에서 통과하는 발판, 원거리 무기, 게임 진행 저장은 포함하지 않습니다.

### 동작 그림과 잡기

**동작 / 연출 그림 불러오기**에서 PNG·JPG·WebP 정지 그림 또는 스프라이트 시트를 등록합니다. 정지 그림은 1×1, 애니메이션은 가로 칸·세로 칸·실제 프레임 수·초당 프레임을 지정합니다. 동일 크기의 칸을 왼쪽→오른쪽, 위→아래로 재생합니다. 최대 256프레임입니다. GIF·동영상은 직접 지원하지 않으며 프레임 시트로 변환해 넣어야 합니다.

**캐릭터 동작**에서 대기·이동·점프·낙하·공격·피격·잡힌 상태 그림을 연결합니다. 오른쪽을 보는 그림을 기준으로 왼쪽 이동 시 반전합니다. 빈 동작은 대기 그림이나 기본 캐릭터로 표시됩니다.

**적 배치** 도구로 맵을 클릭합니다. 적의 이동·감지·체력·접촉 피해와 잡기 여부, 잡기 시간, 탈출 입력 횟수, 잡힌 캐릭터의 상대 위치를 정할 수 있습니다. 적의 **적의 잡기** 그림과 주인공의 **잡힌 상태** 그림이 함께 재생됩니다. 벽과 겹치는 상대 위치는 적용하지 않습니다. 잡힘 중에는 이동·점프·공격이 멈추며, 시간 만료 또는 X 입력 횟수 충족 시 풀립니다. 탈출 직후 잠깐 재포획을 막습니다.

### 조건별 화면 그림 / 애니메이션

**화면 연출 → 화면 연출 추가**에서 그림과 조건을 연결합니다.

- 조건: 항상, 잡힘, 피격, 공격, 공중, 체력 이하, 스위치 켜짐, 아이템 수량 이상. 맵별 제한도 가능합니다.
- 위치·크기: 게임 화면의 백분율. 미리보기에서 드래그해 이동하고 오른쪽 아래 손잡이로 크기를 조절할 수 있습니다.
- 재생: 불투명도, 표시 시간, 반복 여부, 겹침 순서. 표시 시간 0은 조건이 유지되는 동안 표시하며, 반복 해제 시 마지막 프레임을 유지합니다.
- 조건이 꺼지면 숨겨지고, 다시 충족되면 처음부터 재생합니다. 대화창과 조작 버튼은 연출 위에 표시됩니다.
- 스위치·아이템 조건은 기존 이벤트 명령으로 제어할 수 있어 탑다운에서도 사용할 수 있습니다. 잡힘·체력 등의 액션 조건은 횡스크롤에서 동작합니다.

모든 그림과 설정은 `.storyforge` 파일에 포함됩니다. **게임 내보내기**는 횡스크롤과 화면 연출을 포함한 독립 HTML 게임을 만듭니다.
